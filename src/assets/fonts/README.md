# Fonts

Both families are served from this folder. Nothing is loaded from a third-party host.

| Family | Use | License | Source |
| --- | --- | --- | --- |
| Source Serif 4 | Headlines, lore, reading text | SIL Open Font License 1.1 | Adobe, via the Fontsource npm package |
| IBM Plex Sans | Controls, tables, numbers | SIL Open Font License 1.1 | IBM, via the Fontsource npm package |

The license text for each family sits next to the font files in this folder. Only the Latin subset is included.
